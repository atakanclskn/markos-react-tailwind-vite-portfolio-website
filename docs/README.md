# Markos Studio — Dokümantasyon

Bu klasör, projenin teknik dokümantasyonunu içerir. Önerilen okuma sırası:

1. **[STACK.md](./STACK.md)** — Hangi kütüphane ve servisler kullanılıyor?
2. **[ARCHITECTURE.md](./ARCHITECTURE.md)** — Uygulama nasıl parçalara ayrılmış, veri nasıl akıyor?
3. **[ENVIRONMENT.md](./ENVIRONMENT.md)** — Ortam değişkenleri (`.env`) listesi ve anlamları.
4. **[ADMIN.md](./ADMIN.md)** — Yönetim paneli rotaları ve yetkilendirme özeti.
5. **[FIRESTORE.md](./FIRESTORE.md)** — Firestore koleksiyonları ve `siteContent` dokümanları.

Durum ve plan:

- **[../CHANGELOG.md](../CHANGELOG.md)** — Yapılan değişiklikler (sürüm notları).
- **[ROADMAP.md](./ROADMAP.md)** — Öncelikli yapılacaklar listesi.
- **[DURUM_VE_EKSIKLER.md](./DURUM_VE_EKSIKLER.md)** — Eksik alanlar, riskler, “boş” veya yetersiz içerik, üstünde durulmayan konular (**özet: ne kaldı?** için başlangıç noktası).

Kök dizindeki **[../README.md](../README.md)** hızlı kurulum ve projeye giriş içindir.
